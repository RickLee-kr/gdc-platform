### P2 — Global Log Search / Command Palette (review only)

**Need:** Medium-high for power operators after Logs was demoted from sidebar (M30.1).  
**Recommendation:** Defer to M30.4 — implement a scoped command palette (navigate to Governance queue item, open stream, jump to Logs with filters) before full cross-log search.  
**Rationale:** Full-text log search needs backend indexing or client pagination strategy; palette delivers 80% wayfinding value with frontend-only scope.
