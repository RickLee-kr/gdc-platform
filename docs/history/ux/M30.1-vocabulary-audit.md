| Term | Operator label |
|------|----------------|
| `delivery_logs` | delivery records |

| Logo home | `/streams` | `/monitoring` |

| Operations KPI | Route Posture, Destinations | **Delivery issues**, **Risk & governance** |
| Streams filter | Connector filter | **Source product** |
| Streams filter | Source enum filter | **Ingest method** (readable labels) |

| Streams detail | 8-tab default | **Issues rail** (What / Why / Action) |
| Administration hub | Connectors, Routes, Destinations | **Source connections**, **Delivery paths**, **Delivery targets** |
