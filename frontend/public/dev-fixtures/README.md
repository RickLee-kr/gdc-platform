# Dev operational snapshot fixtures

Static JSON matching `OperationalSnapshotResponse` for Phase 6.5 browser validation.

Enable in the app (DEV only):

```js
localStorage.setItem('GDC_RUNTIME_FIXTURE_MODE', '1')
localStorage.setItem('GDC_RUNTIME_FIXTURE_FILE', 'runtime-operational-snapshot-320x120.json')
location.reload()
```

Or use the Runtime fixture mode banner on Runtime Overview / Routes.
