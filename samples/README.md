# Data Relay OSS Sample Pack

Reference JSON for first-stream setup. Import values through the UI wizard or API — these files are not auto-loaded on install.

| Path | Purpose |
|------|---------|
| `http/example-api.json` | HTTP polling connector/source/stream skeleton |
| `mappings/example-mapping.json` | JSONPath field mappings |
| `enrichments/example-enrichment.json` | Static enrichment fields |
| `destinations/example-webhook.json` | Webhook destination |
| `destinations/example-syslog.json` | Syslog UDP destination |

See root [README.md](../README.md) Quick Start for the full install → login → stream flow.
